# تقرير مشروع MeDo ERP — v6.1

> **من التصفير الشامل إلى نظام التجربة الذاتية**
> أُرشف: 13 أكتوبر 2026 · صنعاء — اليمن

---

## 1. الملخص التنفيذي

أُنجز MeDo ERP v6.0 بعد تنفيذ خطة **التصفير الشامل** عبر 9 مهام رئيسية، شملت:
تنظيف Vercel KV، إعادة بناء عزل المنشآت، وإطلاق نظام التجربة الذاتية (7 أيام).

**النتيجة:** منصة مستقرة + عزل موثوق + مسار تسجيل ذاتي كامل.

---

## 2. المشكلة والسبب الجذري

### الأعراض

- اختفاء اسم المنشأة من الرابط (`?tenant=`) فور فتحه.
- ظهور شاشة بيضاء عند فتح `/erp/`.
- خطأ: `TypeError: Cannot read properties of null (reading 'systemSettings')`.
- تعقيد سابق في نظام عزل المنشآت وإدارة الجلسات.

### الأسباب الجذرية

- تراكم الأكواد من محاولات متعددة سابقة.
- **Service Worker قديم** يحذف بارامتر `?tenant=` من كل نقرة.
- حالة `erpState` تبدأ بـ `null` بدون حماية.
- مفاتيح وبيانات وهمية متراكمة في Redis.

> ⚠️ **النقطة الحرجة:** Service Worker لم يكن مُسجَّلاً في الكود الجديد، لكنه ظل حياً في متصفحات المستخدمين السابقين.

### تفصيل تعطيل SW

```js
// public/sw.js
self.addEventListener('install', () => self.skipWaiting());
self.addEventListener('activate', (e) => {
  e.waitUntil(
    caches.keys()
      .then(keys => Promise.all(keys.map(k => caches.delete(k))))
      .then(() => self.registration.unregister())
      .then(() => self.clients.claim())
  );
});
self.addEventListener('fetch', () => {});
